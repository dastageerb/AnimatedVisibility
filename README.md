# AnimatedVisibility

A Jetpack Compose sample showing how `AnimatedVisibility` turns flat UI state changes into smooth, purposeful motion — the small details that make an app feel polished.

## What this covers

- `AnimatedVisibility` for enter/exit transitions (fade, slide, scale, expand/shrink)
- Combining enter + exit transitions so state changes feel natural
- `animateContentSize` for layout changes that don't jump
- When *not* to animate — restraint is a feature

## Run it

1. Clone the repo
2. Open in Android Studio
3. Run on an emulator or device (API 26+)
